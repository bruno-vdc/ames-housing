## **Data**

The dataset (`data/ames_housing.csv`) was created on 12 September 2026 and is based on the Ames Housing dataset described by Dean De Cock in his 2011 article, *[Ames, Iowa: Alternative to the Boston Housing Data as an End of Semester Regression Project](https://jse.amstat.org/v19n3/decock.pdf)*.

The dataset was obtained by installing the `AmesHousing` R package. The package is maintained in [its GitHub repository](https://github.com/topepo/AmesHousing), created by Max Kuhn and other contributors, and provides different versions of the original dataset. For this project, the processed version generated by `make_ames()` was chosen because of its data cleaning, restructuring, and additional geographic information.

Further details about the original and processed versions of the dataset can be found in the [AmesHousing repository](https://github.com/topepo/AmesHousing).

Although the resulting dataset is included in this repository, the R code used to generate it is also available in `data/data.R` to facilitate reproducibility.
